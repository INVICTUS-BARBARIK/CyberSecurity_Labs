
# CyberSecurity Labs

Welcome to my cybersecurity portfolio, where I document my hands-on practice in penetration testing, Linux security, vulnerability analysis, and Capture the Flag (CTF) challenges.

This repository contains completed lab write-ups, technical notes, commands, findings, and lessons learned throughout my cybersecurity journey.

## Areas of Practice

- Network and service enumeration
- Linux enumeration and privilege escalation
- Web application security
- Vulnerability identification and analysis
- Bash and Python for security automation
- Capture the Flag (CTF) challenges
- System and configuration security

## Lab Platforms

### TryHackMe
Hands-on cybersecurity rooms covering penetration testing fundamentals, Linux, networking, and security techniques.

### VulnHub
Vulnerable virtual machines used to practise enumeration, exploitation, and privilege escalation in controlled lab environments.

### Hack The Box
Practical cybersecurity challenges focused on developing technical skills and understanding attack paths.

## Repository Structure

```text
CyberSecurity_Labs/
```

Each platform directory contains its own lab write-ups and supporting evidence where applicable.
